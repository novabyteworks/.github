# NovaByteWorks

We make browser extensions that save pictures and videos from the sites you use into tidy folders on your own computer, and a local gallery, My Library, to find them again. They are made for people who collect reference material, such as artists.

| Extension | Saves from | Install | Bug reports and release notes |
|---|---|---|---|
| **IG Mass Media Downloader** | Instagram | [Chrome Web Store](https://chromewebstore.google.com/detail/ig-mass-media-downloader/pkndnkmpggafjcjbecllfdkeeifdicid) | [instagram-downloader](https://github.com/novabyteworks/instagram-downloader) |
| **TT Mass Media Downloader** | TikTok | [Chrome Web Store](https://chromewebstore.google.com/detail/tt-mass-media-downloader/odeckbdplgkcgnooheajljinmbjalebm) | [tiktok-downloader](https://github.com/novabyteworks/tiktok-downloader) |
| **Mass Media Downloader** | Pinterest, Reddit, X, Bluesky, Tumblr, Threads, Facebook, VSCO | [Chrome Web Store](https://chromewebstore.google.com/detail/ehikbcioolopbfpcckoanobhjaobcdjk) | [mass-media-downloader](https://github.com/novabyteworks/mass-media-downloader) |

The extensions are not open source. These repositories are where you can report a bug, ask for a feature and read what changed in each version.
